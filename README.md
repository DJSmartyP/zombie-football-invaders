# Zombie Football Invaders

A small browser arcade game: stop waves of zombies from reaching your goal by firing footballs at them.

## Play

Open `index.html` in a browser, or play the [GitHub Pages version](https://djsmartyp.github.io/zombie-football-invaders/) once Pages is enabled.

- Move: **Left/Right arrow keys**, **A/D**, mouse, or the touch buttons.
- Shoot: **Space**, click/tap the pitch, or the touch button.
- Pause: **P**.

The game has escalating waves, three lives, optional sound, and a best score saved in the browser. It uses plain HTML, CSS, and JavaScript; no build step is required.
